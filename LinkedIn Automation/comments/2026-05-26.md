The tier order is right — I've seen more pain from skipping tier 2 than from never touching a modal. A virtualized data table with server pagination + AbortController on filter change teaches stale responses and rollback in a week; a marketplace surface hides those bugs behind ten other features. Tier 5's undo/sync stack is brutal if you haven't paid that tax on list-heavy UI first.

## Comment 2 — CRAFT framework
Target: https://www.linkedin.com/posts/yangshun_heres-where-i-think-frontend-engineers-should-share-7461434456847986688-p6Mv/?utm_source=share&utm_medium=member_desktop&rcm=ACoAAC3YDbEB_yE-WKX_VSN0UeD1W2QTnMcm46k

Complexity and Agentic overlap in practice — the streaming UIs I've debugged usually failed on partial tool-call state in the tree, not on missing SSE. Decoupling the network stream from what React reconciles (batch flush boundaries, useDeferredValue on the render path) fixed more than another transport wrapper. Taste there is knowing when not to stream token-by-token at all.
