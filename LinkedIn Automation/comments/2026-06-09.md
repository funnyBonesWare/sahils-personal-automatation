## Comment 1 — Event loop / setTimeout callback (Vasanth Bhat)
Target: https://www.linkedin.com/posts/careerwithvasanth_javascript-activity-7469979982367203328-25sf

Clearing the call stack doesn't garbage-collect the callback — the browser timer in Web APIs still holds a reference to that closure until it fires or you clearTimeout. Once the 10s elapses it lands in the macrotask queue, the event loop sees an empty stack, and a fresh execution context spins up just for that callback. Same reason a dashboard tab left open overnight can keep chewing memory if intervals never get cleaned up in useEffect.
