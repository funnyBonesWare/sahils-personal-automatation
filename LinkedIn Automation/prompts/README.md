# Prompts

Everything Cursor needs to write good content lives in `.cursor/rules/linkedin-automation.mdc` + `content/VOICE.md`. This folder is just for **Sahil's optional daily brief** and a quick guardrail reference.

| File | Purpose |
|------|---------|
| `daily-request.md` | Optional brief — edit before asking *"do today's content"*. Leave blank to let Cursor pick. |
| `guardrails-snippet.md` | Quick reference for the safety rules Cursor enforces. |

You don't need to read or copy these into chat — Cursor picks up `daily-request.md` automatically when you ask for today's content.
